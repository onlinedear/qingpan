# 轻盘 · 减脂期的麦当劳搭配助手

> 今天也能吃麦当劳，只是吃得更聪明。

设定热量上限和蛋白质下限，轻盘从你附近门店的**实时菜单**里配出一份达标的托盘，营养只用麦当劳官方数据，价格用门店算价确认。

本项目参加 **2026 麦当劳程序员创意开发大赛（1024 程序员节）**，由参赛者独立开发，非麦当劳官方产品。

- 🌐 在线体验：[qingpan-67r.pages.dev](https://qingpan-67r.pages.dev)
- 🧩 Agent Skill：[`skill/SKILL.md`](skill/SKILL.md)
- 🔌 MCP 集成说明：[`MCP_INTEGRATION.md`](MCP_INTEGRATION.md)

## 玩法

| 玩法 | 说明 |
|---|---|
| 托盘配餐 | 拖动热量、切换蛋白质档位，托盘实时重配；营养成分表数字逐位翻牌，热量环弹簧填充 |
| 换一件 | 左右滑动卡片（或点箭头）换同类餐品，其余保持不变 |
| 走着去 | 高德步行路线画出往返路径，估算能抵掉多少千卡并计入热量环 |
| 天气菜单 | 下雨降温优先热饮，高温优先清爽无糖，首屏文案随天气变化 |
| 摇一摇盲盒 | 晃一晃手机，在目标内随机抽一盘，卡片依次翻转揭晓 |
| 营养标签分享卡 | 一键生成营养成分表风格的海报，浏览器本地绘制 |
| 7 天轻盘挑战 | 连续打卡解锁 7 种托盘纸花纹，记录只存在本机 |

没有可靠营养数据的餐品**不参与配餐**，单独列出；菜单名不带规格时按中杯/中份估算，界面标「≈」并说明按哪个规格算的。

## 目标用户

- 控制热量、减脂或增肌期间仍想吃麦当劳的人
- 想快速知道「这家店怎么点更均衡」的上班族和学生
- 想在 Agent 里一句话配餐的 MCP 用户（见 Skill）

## 使用方式

### 1. 网页（零安装）

打开在线体验地址，输入「城市 + 地点」（如 `上海市人民广场`）或点定位按钮。

### 2. Agent Skill

把 [`skill/`](skill/) 复制到支持 Agent Skills 的客户端，然后对 AI 说：

> 我在上海人民广场，想吃麦当劳，600 大卡以内、蛋白质 25 克以上，帮我配一份。

或者直接命令行运行（Node.js 18+，无第三方依赖）：

```bash
export MCD_MCP_TOKEN='你的 Token'   # 去 https://open.mcd.cn/mcp 控制台激活获取，只放本机环境变量
node skill/scripts/plan.mjs --city 上海市 --keyword 人民广场 --kcal 600 --protein 25
```

### 3. 自己部署

```bash
npm test                     # 离线测试，不需要 Token、不连网
npm run dev:static           # 纯静态预览（示意数据）http://127.0.0.1:8765
npx wrangler pages dev       # 带 /api 的完整预览，密钥写在 .dev.vars（已被 .gitignore 忽略）
npx wrangler pages deploy    # 部署到 Cloudflare Pages
```

需要的密钥（在 Cloudflare Pages 后台 → Settings → Variables and Secrets 配置）：

| 变量 | 说明 |
|---|---|
| `MCD_MCP_TOKEN` | 麦当劳中国 MCP Token（体验模式；服务端只放行公共工具，个人权益不外泄） |
| `AMAP_KEY` | 高德 Web 服务 Key（可选；不配时天气和步行路线使用示意数据） |

```

```

## 安全与隐私

- Token 只通过环境变量 / Cloudflare 密钥读取，不写入代码、日志或报告；仓库不含任何真实 Token、手机号、地址、订单或券码。
- 只读白名单：下单、取消、领券、兑换、抽奖、新增地址等写操作一律不调用。
- 体验模式下，`calculate-price` 返回的站点主人个人折扣与权益余额在服务端剔除。
- 定位只在点击后请求，坐标粗化到约百米且不保存；打卡记录只存本机浏览器。
